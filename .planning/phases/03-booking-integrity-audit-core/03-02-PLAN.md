<task type="auto">
  <name>Task 2: Build Transactional Booking Service with Row-Level Locking</name>
  <files>src/lib/booking/service.server.ts</files>
  <read_first>src/db/schema.ts, src/db/client.server.ts, src/lib/booking/availability.ts, src/lib/booking/dormitory.ts, src/lib/booking/state-machine.ts</read_first>
  <action>Create `src/lib/booking/service.server.ts` implementing core database operations wrapped in Drizzle transactions (`db.transaction`):
1. `createBookingRequest(input)`:
   - Begin transaction, lock asset via `tx.select().from(assets).where(eq(assets.id, assetId)).for('update')` (D-01).
   - Validate asset status is active.
   - For rooms: validate requested attendance <= capacity (D-10), check daily operating hours (D-11), check date closures, check for overlapping approved bookings (D-04).
   - For dormitories: validate closures (D-11) and check date-by-date shared capacity via `checkDormitoryCapacity` (D-09).
   - If any validation fails, throw HTTP 409 Conflict error with structured details (D-02).
   - Insert new booking with `status: 'pending'` and return created booking.
2. `approveBooking(bookingId, actorId)`:
   - Begin transaction. Read target booking. Validate `validateBookingTransition(booking.status, 'approved')` (D-05).
   - Lock asset row with `FOR UPDATE` (D-01).
   - Re-check availability/capacity for the booking's time slot against current approved bookings (FLOW-05). If occupied, throw HTTP 409 Conflict (D-02).
   - Update booking status to `'approved'` and `updatedAt: new Date()`.
3. `rejectBooking(bookingId, actorId, rejectionReason)`:
   - Begin transaction. Read target booking. Validate `validateBookingTransition(booking.status, 'rejected', rejectionReason)` (D-05, D-06).
   - Update booking status to `'rejected'`, `rejectionReason`, and `updatedAt`.
4. `cancelBooking(bookingId, actorId, isPublicReference?)`:
   - Begin transaction. Read target booking. Validate `validateBookingTransition(booking.status, 'cancelled')` (D-05, D-07).
   - Update booking status to `'cancelled'` and `updatedAt`.</action>
  <verify>npx tsx -e "import { BookingService } from './src/lib/booking/service.server'; console.log('BookingService loaded:', !!BookingService)"</verify>
  <acceptance_criteria>
    - `service.server.ts` locks asset rows using `.for('update')` in all mutation transactions.
    - Throws HTTP 409 Conflict when slots are unavailable or capacity exceeded.
    - Enforces state machine transitions on approve, reject, and cancel.
  </acceptance_criteria>
  <done>src/lib/booking/service.server.ts is implemented</done>
</task>
