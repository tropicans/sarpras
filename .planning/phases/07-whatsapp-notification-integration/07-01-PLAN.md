2. Create `src/lib/whatsapp/phone.ts` implementing `normalizePhoneNumber(rawPhone: string): string | null` and `sanitizeTarget(target: string): string | null`:
   - Supports single numbers: strips non-numeric characters, normalizes `08...` / `+628...` / `8...` to `628...`, enforces 10–15 digits length.
   - Supports comma-separated phone lists: splits by `,`, normalizes each number, filters out invalid entries, re-joins with `,`.
   - Supports WhatsApp Group IDs (e.g. `120363xxx@g.us` or `xxx-xxx@g.us`): returns as-is if valid group pattern.
   - Returns `null` for empty/invalid phone inputs without throwing runtime errors.
3. Create `src/lib/whatsapp/phone.test.ts` verifying all normalization rules and edge cases.
