1. `submitBookingRequestFn`: Validates public booking input via Zod schema, calls `createBookingRequest`, records audit event with `actorType: 'system'` / requester identity, returns created booking with reference ID.

3. `rejectBookingFn`: Protected with `authMiddleware` and `requireMinRole('operator')`. Rejects booking with required `rejectionReason` and records audit event with admin `actorId`.
4. `cancelBookingByAdminFn`: Protected with `authMiddleware` and `requireMinRole('operator')`. Cancels booking and records audit event.
5. `cancelBookingByPublicReferenceFn`: Public endpoint accepting booking ID and reference token, verifying matching requester reference, executing cancellation, and recording audit event (D-07).</action>
  <verify>npx tsx -e "import { approveBookingFn, submitBookingRequestFn } from './src/lib/booking/server-fns.server'; console.log('Server functions loaded:', !!approveBookingFn && !!submitBookingRequestFn)"</verify>
  <acceptance_criteria>
