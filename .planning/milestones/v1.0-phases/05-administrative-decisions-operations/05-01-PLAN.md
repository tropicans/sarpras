  <action>Create `src/lib/booking/admin-fns.server.ts` protected with `.middleware([authMiddleware])` defining:
1. `getAdminDashboardOverviewFn`:
   - Aggregates counts: pending bookings needing action, approved bookings this calendar month, total active assets, and active closures.
   - Retrieves top 5 most recent pending bookings (`urgentPending`) with requester info, asset name, and scheduled dates for fast dashboard action.
2. `getAdminBookingsFn`:
   - Validates input with Zod schema: `status` ('all' | 'pending' | 'approved' | 'rejected' | 'cancelled'), `assetType` ('all' | 'room' | 'dormitory'), `startDate` (optional string), `endDate` (optional string), `search` (optional string), `page` (number, default 1), `limit` (number, default 10).
   - Executes dynamic Drizzle query joining `bookings` and `assets`.
   - Returns `{ items: Array<BookingWithAsset>, total: number, page: number, totalPages: number }`.
3. `getBookingConflictContextFn`:
   - Validates `bookingId: z.string().uuid()`.
   - Queries target booking with joined asset info and full requester details.
   - Queries overlapping approved bookings (`hasHardConflict: boolean`, list of approved conflicts with requester name, org, dates).
   - Queries overlapping pending bookings (`hasPendingOverlaps: boolean`, list of competing pending requests).
   - Returns `{ target, hasHardConflict, approvedConflicts, pendingOverlaps }`.
4. `approveBookingAdminFn`:
   - Validates `bookingId: z.string().uuid()`.
   - Executes `BookingService.approveBooking(bookingId, session.user.id)` inside transaction.
   - Returns `{ success: true, booking }`.
5. `rejectBookingAdminFn`:
   - Validates `z.object({ bookingId: z.string().uuid(), rejectionReason: z.string().min(3, "Alasan penolakan minimal 3 karakter") })`.
   - Executes `BookingService.rejectBooking(bookingId, session.user.id, rejectionReason)`.
   - Returns `{ success: true, booking }`.
6. `getAdminCalendarEventsFn`:
   - Validates `z.object({ assetId: z.string().uuid().optional(), assetType: z.enum(["all", "room", "dormitory"]).optional(), start: z.string(), end: z.string() })`.
   - Queries bookings in range with status `approved` or `pending` (excluding `rejected` and `cancelled`).
   - Queries `assetClosures` for the matching assets in range.
   - Returns combined array of formatted calendar events with event type (`approved`, `pending`, `closure`), asset metadata, requester summary, and timing.</action>
