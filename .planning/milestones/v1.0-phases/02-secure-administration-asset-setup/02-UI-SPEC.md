## Visual Hierarchy & Focal Points

### 1. Login Page
- **Primary Focal Point**: Isomorphic Login Card container centered on the screen, highlighted by a subtle border (`border-border`) and slight shadow.
- **Focal Action**: "Sign In" button using Accent color background (`#09090b`), drawing the user's primary attention.
- **Support Elements**: Username and password labels in Label role, inputs with standard borders.

### 2. Administrator & User Dashboard
- **Primary Focal Point**: Summary stats cards at the top of the main content area (e.g. Active Users, Total Assets, Total Closures).
- **Focal Action**: Sidebar navigation selected item (highlighted with Accent color active background and Label role).
- **Secondary Focal Point**: Table listings showing assets or administrators, with light header backgrounds (`#fafafa`).
