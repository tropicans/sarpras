   - Strictly omits: `requesterName`, `requesterPhone`, `requesterEmail`, `requesterOrganization`, and `purpose` from the projection unless looking up specifically by self.
   - Returns null if not found.</action>

  <name>Task 2: Create Public Server Functions</name>
  <files>src/lib/booking/public-fns.server.ts</files>

  <action>Create `src/lib/booking/public-fns.server.ts` defining TanStack Start public server functions using `createServerFn`:
1. `getPublicAssetsListFn`:
   - Method: GET
   - Queries all assets where `status = 'active'`, ordered by name.
   - Returns array of `{ id, name, type, location, capacity, status }`.
2. `getAssetPublicScheduleFn`:
   - Method: GET
   - Validator: `z.object({ assetId: z.string().uuid(), month: z.string().optional() })` or `z.string().uuid()`
   - Queries approved bookings and asset closures for the given asset.
   - Returns `{ bookedSlots: Array<{ startDate: string; endDate: string; status: 'booked' }>, closureSlots: Array<{ startDate: string; endDate: string; reason: string | null; status: 'closed' }> }`.
   - Strictly omits requester personal data (D-02, ASSET-04).
3. `checkAvailabilityPreflightFn`:
   - Method: POST
   - Validator: `z.object({ assetId: z.string().uuid(), startDate: z.string(), endDate: z.string(), attendance: z.number().int().positive().optional() })`
   - Calls `BookingService.checkPreflightAvailability` and returns the availability status.
4. `getPublicBookingStatusFn`:
   - Method: GET
   - Validator: `z.object({ ref: z.string().min(1) })`
   - Calls `BookingService.getPublicBookingStatus(ref)` and returns the sanitized booking record or 404 error.</action>
