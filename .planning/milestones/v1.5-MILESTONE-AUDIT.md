## 3. Cross-Phase & End-to-End Integration

- **Admin to Database**: Admin creates or edits an asset with custom facility tags in `/admin/assets` -> `saveAssetFn` runs `sanitizeFacilities` -> inserts/updates `assets.facilities` in PostgreSQL with JSONB type -> records audit logs.
- **Database to Public UI**: Public catalog queries `getPublicAssetsListFn` or `getPublicAssetByIdFn` -> `getAssetFacilities(asset)` resolves custom tags if present; otherwise cleanly falls back to `CATEGORY_FACILITY_PRESETS[asset.type]`.
- **Public Modals & Wizard**: Discovery card (`AssetCard`), Schedule overview modal (`ScheduleModal`), and Multi-step booking form (`/book/$assetId`) accurately render the exact same facility badges.
