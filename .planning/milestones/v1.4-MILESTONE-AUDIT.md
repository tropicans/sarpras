## 1. Executive Summary

Milestone `v1.4` successfully addressed the critical bug blocking Google OAuth (passwordless) users from enabling Two-Factor Authentication (TOTP), which threw a `400 Bad Request: "Invalid password"` error.

## 4. End-to-End User Flows

1. **2FA Activation Flow:**
   - Admin opens 2FA Setup Modal &rarr; Clicks "Mulai Aktivasi 2FA" &rarr; Better Auth generates `totpURI` &rarr; UI renders QR code and manual secret key &rarr; User scans in Google Authenticator &rarr; User enters 6-digit code &rarr; 2FA activated & 10 backup codes generated & copied &rarr; **Verified**.
2. **2FA Login Challenge Flow:**
   - User with 2FA enabled logs in &rarr; Redirected to `/two-factor` &rarr; Enters 6-digit TOTP code or emergency backup code &rarr; Validated and navigated to `/admin` &rarr; **Verified**.
3. **2FA Safe Deactivation Flow:**
   - User opens modal with active 2FA &rarr; Clicks "Nonaktifkan 2FA" &rarr; `authClient.twoFactor.disable({})` runs &rarr; Status toggled to false without requiring password &rarr; **Verified**.
